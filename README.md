# 7-Day Cloud Honeypot Attack Surface & Threat Analysis

An empirical cybersecurity investigation analyzing 7 days of live attack telemetry collected from a medium-interaction Cowrie SSH/Telnet honeypot deployed on an exposed cloud virtual machine.

---

## 🎯 Project Overview

- **Deployment Duration:** 7 Consecutive Days (168 Hours)
- **Honeypot Framework:** Cowrie (Medium Interaction)
- **Target Ports Exposed:** Port 22 (SSH) and Port 23 (Telnet)
- **Goal:** Capture brute-force credential trends, map attacker geolocation profiles, and identify automated post-exploitation command chains.
